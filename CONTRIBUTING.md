# Contributing

Sanitized transcripts only. If a log contains private architecture, real machine paths you would not publish, prompts, or secrets, do not send it here.

Useful contributions:

- Parsers for another product's visible export format
- Tests around resume-gate and symmetric-probe detection
- Counterexamples that should *not* match a seed pattern
- Better confidence scoring that still requires excerpts

Run:

```bash
python -m pytest
```
