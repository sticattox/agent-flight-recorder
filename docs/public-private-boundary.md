# Public / private boundary

This repository is public on purpose. It must stay boringly safe.

## Public

- Recorder software and schemas
- Seed operating patterns with generic wording
- Fabricated sample transcripts
- Example traces and library output
- Documentation and tests

## Private — keep out

- Internal architecture documents
- Real product source
- Proprietary prompts
- Private chat logs
- Machine paths that identify a private lab
- Credentials, user data, backups

If a transcript cannot be sanitized, do not ingest it into a public library. Run AFR locally and keep the trace off GitHub.
